# Imagens da Landing Page

Para que a landing page funcione corretamente, adicione as seguintes imagens nesta pasta:

## Arquivos Necessários

1. **dashboard-admin-devices.png** (1000x600px recomendado)
   - Imagem mostrando o dashboard administrativo em laptop, tablet e smartphone
   - Deve mostrar: gráficos, pedidos, menu lateral
   - Posição na landing: Seção "Painel admin + App cliente"

2. **app-menu-screenshot.png** (400x800px recomendado)
   - Screenshot do cardápio digital no smartphone
   - Deve mostrar: categorias, produtos com fotos, preços
   - Posição na landing: Seção "Interface do cliente"

3. **qr-code-table.png** (400x600px recomendado)
   - QR Code na mesa do restaurante
   - Deve mostrar: suporte acrílico com QR Code, smartphone scaneando
   - Posição na landing: Seção "QR Code na mesa"

4. **checkout-payment.png** (400x800px recomendado)
   - Tela de checkout do mobile
   - Deve mostrar: resumo do pedido, opções PIX/Cartão, total
   - Posição na landing: Seção "Checkout profissional"

## Como Adicionar as Imagens

1. Salve as imagens em formato PNG ou JPG
2. Coloque nesta pasta (`public/images/`)
3. Garanta que os nomes correspondem exatamente aos listados acima
4. Faça upload no Hostinger

## Dicas

- Use as imagens em alta resolução (mínimo 2x para retina displays)
- Certifique-se que as imagens têm fundo branco ou transparente
- Optimize as imagens (use TinyPNG ou similar)
- As dimensões recomendadas são apenas sugestões, adapte conforme necessário
